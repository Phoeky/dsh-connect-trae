## v3.3.0（2026-10-11）

> **卡片按 WorkBuddy 的组织方式全面重做；国际版也有输入框读数了（显示套餐）；新增「一键测试所有模型」。**

这是一次 **minor** 升级。三条主线：

- **卡片全面对齐 `dsh-connect-workbuddy`**。用户反馈「你这种选择的样式……都和 WorkBuddy 有区别」，随后确认推翻上一版的形态。开关回到**平台原生复选框**、设置区回到**裸行即点即存**（去掉「保存 / 放弃修改」）、账号区回到**定宽网格表格**、签到按钮并入账号行。
- **国际版不再是二等公民**。输入框读数此前只服务国内版，国际版用户打开开关**什么都没有**；现在国际版显示**套餐**（`Pro` / `Free`），且开关在两个 tab 都可见。同时删掉了国际版那个独立的「订阅状态」框——它与账号表额度列渲染同一个值。
- **修好一个「刷新了但没保存」的缺口**。以前「刷新账号与 Token」会提示「仍绑定 X」，而设置文档里其实是空的，重启后静默改回别的账号。

> **npm 上的 `latest` 此前是 3.0.1** —— **3.1.0 / 3.1.1 / 3.2.0 均未发布到 npm**（它们是同一天的内部迭代里程碑）。因此从 npm 升级会一次性拿到下面全部内容。
>
> 其中 **3.2.0 的一部分设计在本版被推翻**：3.2.0 把设置区做成草稿式保存（点「保存」才生效）、账号表格含「Token 到期」列，这些在 3.3.0 里都已不存在。以本版实际行为为准。

### 新增

- **一键测试所有模型** —— 模型区在「一键测试启用模型」旁新增按钮，对当前 region 的**全部可见模型**发起可用性探测。两个按钮共用同一套探测路径，唯一区别是提交的 id 集合。想知道「没启用的那些到底还能不能用」时用它——比如套餐降级之后。
- **输入框读数扩展到国际版** —— 国内版显示 `Trae CN · <余额>`，国际版显示 `Trae 国际版 · <套餐>`。**两边显示的东西不同，这是数据决定的**：国际版的用量文档由订阅状态构建、根本不含积分字段，所以显示它真正有的那个值。
  - 浮层表格随之区域化：列头在国内版是「通用积分」、国际版是「套餐」；面板标题同理。在国际版面板里写「通用积分」而下面是 `Pro`，是在命名一个不存在的量。
- **读数的开关在两个 tab 都可见** —— 此前该开关是国际版专属地缺失，等于让国际版读数从任何入口都够不着。仍是同一个设置、同一次写入，不是第二个开关。
- **`/usage` 的每个积分包携带到期时刻**（`credits.accounts[].expiresAtMs`，外部贡献 [PR #31](https://github.com/dingminhua/dsh-connect-trae/pull/31)）—— 为第三方只读消费者回答「哪一笔先到期」。没有可用时刻的包**不带该字段**（而不是给 0）：`0` 是 1970，会排在所有真实日期之前。

### 界面重做（对齐 WorkBuddy）

| | 上一版 | 3.3.0 |
| --- | --- | --- |
| 开关样式 | 自绘圆钮（34×20 轨道 + 旋钮） | **原生复选框 + `accent-color`** |
| 设置区 | 边框盒子 + 标题 + 保存/放弃按钮 | **裸行，点击即写** |
| 账号区 | 两行式列表，无表头 | **定宽网格表格 + 表头行** |
| 当前账号标记 | 淡色底 | **左侧强调竖条 + 淡色底** |
| 签到 | 全卡唯一一个按钮 | **每行一个**（奖励直接写在按钮上） |

- **列宽改为容器的分数**（`1.7fr 1.1fr 1fr 1.1fr`）——这是「表格难看」的真正原因：上一版四列各自按内容撑开，列与列在行间对不齐。定宽后可以沿列向下读。国际版没有签到列（该 region 无签到接口），列数降为 3。
- **「Token 到期」整列移除** —— 它独占一列却没有人据此做决策。
- **文案精简** —— tab 提示、设置说明、账号说明、开关说明等 15 处长段落各压缩为一行，关键信息不丢，完整解释移入 `title` 提示。

### 修复

- **「刷新账号与 Token」显示已绑定，设置里却是空的** —— 根因是把路由的 `selected` 标志读成了「已经绑定过」，而它回答的是「哪个账号正在使用」。没保存过绑定时存储层用**探测到的默认值**来回答，于是「从未显式绑定」被读成「无需写入」——刷新什么都没保存，卡片却显示成已绑定，下次存储重建就静默改回别的账号。现在按「该区域实际在用的账号」写盘，提示语也区分「已绑定 X」（真的写入了）与「仍绑定 X」（这次没写）。
- **`TraeUsagePack.endTimeMs` 装的是秒，不是毫秒**（外部贡献，PR #31）—— 字段名写的是 `Ms`，而 Trae 给的 `end_time` 是秒：真机 `1788340660` 是 2026-09-02，按毫秒读则是 1970-01-21。此前该字段**没有任何读取方**所以没暴露；任何照名字取用的调用方都会拿到一个排在所有真实日期之前的日期。现在按量级归一。
- **三处静默失效（任何行为测试都测不到）**：
  - **游离的右括号吞掉一整条规则** —— `.dsm-trae-models-actions` 后多了一个 `}`（193 个 `{` 对 194 个 `}`），让紧随其后的积分耗尽提示框**完全不生效**（没有琥珀底、没有边框、flex 失效）。jsdom 不做层叠计算，所以它骗过了当时全部 517 个测试。
  - **6 个 DSH 并不存在的 token** —— `var(--nope, #333740)` 是合法 CSS、**看起来已被兜底**，但兜底值在两个主题下都生效：浅色主题下按钮一 hover 变成深炭色而文字仍是近黑，**几乎看不见**；深色主题下每个通道只差 2，**等于没有反馈**。
  - **深色主题下开关旋钮不可见** —— 旋钮硬编码 `#fff`，而轨道用的是 DSH 的**反差色**（深色主题下近白），于是白配白。（该项随圆钮一起被原生复选框取代。）
- **「仍绑定在上一个账号」提示看不懂** —— 改为同时点名两个账号（`Trae 已登录 X，但本插件绑定的是 Y。`），按钮也点明目标（`改用 X`）。
- **删除国际版独立的「订阅状态」框** —— 它与账号表额度列渲染同一个值，而它能说的永远只是被标为「当前使用」的那行已经说过的内容。

### 测试

全仓 **534 例**（55 个文件）通过，`typecheck × 2` 与 `build` 全绿。

新增/改写的防线包括：括号平衡与 token 白名单（各对应一个已发生的真实故障）、刷新账号后「卡片显示的账号必须是设置里记录的账号」6 条、国际版读数与开关可见性、以及「全卡不得出现批量签到控件」的防回归。
